# Checklist de entrega al cliente

- [ ] Cuentas y accesos transferidos (servidor, dominio, GitHub, Sentry, backups).
- [ ] Usuarios iniciales creados: administrador, vendedor, almacén.
- [ ] Backup automático activo y **restauración probada** al menos una vez.
- [ ] Secretos rotados y guardados por el cliente (no solo por el desarrollador).
- [ ] Alertas de Sentry llegando a un correo del cliente.
- [ ] `RUNBOOK.md` completado con datos reales.
- [ ] Manual breve para cada rol (administrador, vendedor, almacén).
- [ ] Actualizaciones: acordado quién aplica parches de seguridad y cada cuánto (o versión fija documentada).
- [ ] Conector de IA: activado o desactivado, con la clave de integración entregada o revocada.
- [ ] Datos de prueba eliminados.
- [ ] Acta de entrega firmada y alcance de soporte posterior definido.
